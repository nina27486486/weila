## 审查发现

### 已关闭的高风险阻断

#### 1. Credential Manager 读取异常可能在 `runApp` 前终止启动：已修复

- 修复：`DanmakuCredentialManager.initialize()` 捕获后续安全存储读取异常，清空运行时凭据并返回安全的 `failed` 迁移状态，不再把异常抛到 `main()`。
- 数据安全：读取失败时不删除旧 Hive 明文，设置页继续显示安全迁移失败及重试入口。
- 回归测试：`secure store read failure becomes a recoverable migration state` 先以未捕获异常失败，修复后通过。

#### 2. 安全报告字段净化仍是黑名单：已修复

- 修复：外部文本标识只允许 ASCII 字母、数字、点、下划线、加号和连字符，最长 120 个字符；其他值整体输出 `[redacted]`。
- 线路健康标签只接受内部固定值 `未知`、`良好`、`一般`、`不稳定`。
- 回归测试覆盖 API key、Cookie、百分号编码 URL、任意等号查询格式和脚本片段，并验证正常版本、平台、内容 ID 与中文健康标签仍可输出。

#### 3. 弹幕异步晚到时重放经过时间段：已修复

- 修复：新弹幕列表加载完成后，以控制器最新播放时间进行二分定位，只保留当前位置附近及未来弹幕，不再从索引 0 开始发射。
- 现有会话请求代次继续拒绝旧作品/旧集数的过期异步结果。
- 回归测试先复现“播放已到 30 秒，晚到数据一次发射 3 条”，修复后只发射 30 秒附近的 1 条；既有 seek、回退和明显前跳测试保持通过。

#### 4. 调试日志和详情错误泄漏完整媒体信息：已修复

- 新增纯 Dart 播放错误分类与受控日志格式，播放器只记录操作名和 `failureKind`。
- 完整媒体 URL、原始 `media_kit` 消息、加载集数/解析片源异常不再进入播放器日志。
- 详情页不再把底层 `$e` 显示给用户，改为通用可恢复提示。
- 源码负向测试和脱敏器测试覆盖签名 URL、Header、Token 与本机路径。

#### 5. Windows 可执行文件元数据为模板值：已修复

- `windows/runner/Runner.rc` 的 Company、FileDescription、ProductName 与版权信息已统一为 `Weila`。
- 文件级回归测试禁止重新引入 `com.example`，构建后 EXE 元数据复核通过。

#### 6. 版本号存在双来源

- `pubspec.yaml:4`
- `lib/utils/constants.dart:3`

当前分别为 `0.4.0+4` 与 `0.4.0`，语义版本一致；新增测试会在两者不一致时失败。设置页和弹弹play User-Agent 使用常量，最终升级到 `1.0.0+5` 时仍必须同步，长期建议从构建元数据生成单一版本来源。

#### 7. 安装升级测试仍未完全覆盖

Inno Setup 的稳定 AppId、每用户安装路径和默认保留用户数据策略符合计划。主人已在当前账户完成覆盖安装，确认应用无白屏、收藏/历史/追番数据和 `Weila/Dandanplay` 凭据保留；但现有烟雾脚本仍未在干净账户执行静默安装和卸载，也没有验证下载保留、旧文件清理及凭据在卸载后保留。当前机器已有安装时脚本会主动中止，这是正确的保护行为，不应绕过。

### 低风险与结构债务

- `player_page.dart` 约 922 个物理行，`detail_page.dart` 约 885 行；新增协调器和控制器均控制在约 500 行内，已接近目标。
- 页面使用 `part` 扩展后仍直接访问大量私有状态，属于“文件拆分”而不是完全的展示/控制解耦。1.0 可以接受，后续 Android 响应式界面应继续收口接口。
- `settings_components.dart`、首页、插件服务和搜索页仍超过约 1000 行，不属于本轮定向拆分范围。
- GitHub Actions 依赖按版本标签引用，后续可固定到提交 SHA 以提高供应链可重复性。
- 换行符警告不会阻止当前构建，但应避免全仓格式化或无关换行重写。

## 数据兼容审查

- 本批改动没有新增 Hive `typeId`，目录索引继续使用版本化 Map。
- 收藏、历史、追番和下载中的 `contentId` 为追加式可空字段，旧 URL key 保持可读；未发现本轮重键、自动合并或删除旧记录。
- 目录缓存恢复只针对 `catalog_query_cache_v1` 的未知类型错误，并带共享冲突重试；不会删除目录实体、引用或旧用户数据 box。
- 凭据迁移遵守“写入 Credential Manager并回读成功后才删除 Hive 明文”；生产路径不回退使用旧 Hive 明文。安全存储读取失败现在只降级为可恢复状态，并保留旧数据。
- 未发现会强制覆盖旧收藏、历史、追番或下载数据的安装脚本指令。
