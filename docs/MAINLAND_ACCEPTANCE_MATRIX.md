真实大陆视频源只由主人在中国大陆网络运行。美国开发网络只运行自动测试、FakePlayer
和弹弹play真实 API 测试，不主动探测大陆媒体地址。

应先转换为 JSONL 或 JSON 数组。

## 样本

每个启用片源至少选择 3 部作品，每部测试首集和最新集，共 6 个会话。每个会话连续
播放 2 分钟，并依次覆盖：

1. 等待首帧并正常播放。
2. 暂停 5 秒后恢复。
3. 拖动到中段。
4. 有多线路时换线。
5. 有多清晰度时切换清晰度。
6. 关闭并重新开启弹幕。
7. 移动鼠标显示底部控制栏，点击“验收报告”，保存复制出的安全 JSON。

“验收报告”在正常播放、缓冲和失败会话中均可使用；失败诊断面板中仍保留另一处
“复制验收报告”按钮。复制成功后界面会明确提示报告不含凭据、弹幕正文与媒体 URL。

## 通过门槛

- 每片源至少 5/6 会话成功。
- 首帧中位数 ≤8 秒，单次 ≤20 秒。
- 换线或清晰度切换后的进度误差 ≤3 秒。
- 没有持续 25 秒以上的重缓冲。
- 预期有弹幕的样本满足：`episodeId != null`，`commentCount`、`parsedCount`、
  `queuedCount`、`renderedCount` 均大于 0，且 `errorStage = "none"`。

报告应只粘贴应用生成的安全 JSON。不要回传完整媒体 URL、请求头、Cookie、AppId、
AppSecret、文件路径、弹幕正文或原始播放器日志。

失败项按 `failureKind` / `errorStage` 分派到播放解析、媒体打开、弹幕同步或渲染模块，
然后执行“回归测试 → 修复 → 新候选包 → 重测”的闭环。
